# Surgify MVP

Surgify is a mock-data React MVP for breast surgery care pathway optimisation.

The project now includes a simple product landing page and a clickable demo frontend. The landing page introduces Surgify to breast surgeons, and the `See Demo` buttons open the pathway review app.

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Screens

- Landing page
- Dashboard
- Surgeries
- Surgery detail
- Settings

## Stack

- React
- TypeScript
- Tailwind CSS
- Vite
- Mock JSON data
- Local component state for accept, defer and dismiss actions
- Generated clinical hero image saved in `src/assets`
